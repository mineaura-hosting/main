DROP-IN BRANDING ASSETS
=======================

Place the four official MineAura PNGs in this folder using these exact names:

  favicon.png            Hexagonal MineAura logo  (used for favicon, navbar mark, footer mark)
  minecraft_title.png    Pixel-art MineAura wordmark  (navbar + footer)
  minecraft_title_2.png  AURA VPS PLANS title artwork  (VPS plans section)
  minecraft_title_3.png  AURA BUDGET PLANS title artwork  (Budget plans section)
  minecraft_title_4.png  AURA ADVANCED PLANS title artwork  (Advanced plans section)

Until a file exists, the site shows a clean typographic fallback in its place
(no broken image icons). The PNGs are used exactly as supplied — never cropped,
recoloured or rescaled beyond proportional fitting.

Keep the original transparency and aspect ratios: the CSS only constrains the
height and keeps width automatic.

  hero-island.svg  is a MineAura-generated decorative illustration (not a branding
  asset) and can be replaced or removed freely.
